# 🇧🇷 Brasil em Sabores

> Uma viagem pelos sabores, tradições e histórias que fazem parte da culinária brasileira.

## 📖 Sobre o projeto

**Brasil em Sabores** é um site informativo desenvolvido para apresentar a diversidade da culinária brasileira através das cinco regiões do país: **Norte, Nordeste, Centro-Oeste, Sudeste e Sul**.

O projeto busca mostrar que a comida brasileira vai muito além dos pratos em si. Cada receita carrega histórias, ingredientes, tradições e influências culturais que ajudam a construir a identidade de cada região.

Além das comidas típicas regionais, o site também apresenta alguns dos sabores que ultrapassaram suas regiões de origem e conquistaram o Brasil.

---

## 🍽️ O que você encontrará no site

### 🌿 Cinco regiões brasileiras

O projeto possui páginas dedicadas a:

- 🌳 **Norte**
- ☀️ **Nordeste**
- 🌾 **Centro-Oeste**
- 🧀 **Sudeste**
- 🧉 **Sul**

Em cada região são apresentados pratos típicos, informações culturais e curiosidades relacionadas à culinária local.

### 🇧🇷 Sabores que conquistaram o Brasil

O site também possui uma seção especial com alguns alimentos que ganharam grande popularidade em diferentes partes do país:

- 🍫 Brigadeiro
- 🍗 Coxinha
- 🥟 Pastel de Feira
- 🌽 Tapioca
- 🍰 Bolo de Rolo

Cada prato possui uma área com informações adicionais sobre sua história e importância cultural.

## 💻 Tecnologias utilizadas

O projeto foi desenvolvido utilizando tecnologias fundamentais para o desenvolvimento web:

- **HTML5** — estrutura das páginas
- **CSS3** — estilização, layout e responsividade
- **JavaScript** — interações e funcionalidades
- **Google Fonts** — tipografia do projeto

As fontes utilizadas são:

- **Playfair Display** — títulos
- **Poppins** — textos e elementos de interface
